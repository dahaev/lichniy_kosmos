# Утверждённые решения — 11.11.2026

1. Проект полностью переписывается с нуля; старый код не переносится механически.
2. Технологическая цель: Go + Vue 3 + TypeScript + PostgreSQL.
3. Первый релиз — MVP: одна платная по коду услуга «Натальная карта»; без оплаты на сайте.
4. Главная страница должна соответствовать `frontend/references/hero-approved.png` по композиции и визуальному характеру.
5. **Приоритетный новый путь пользователя:** главная → анкета рождения (4 шага, без регистрации/кода) → проверка данных → получение/активация уже имеющегося права (код или кабинет) → согласие и атомарное создание заказа → анимация построения/генерация → сохранённый результат. Это решение заменяет старый порядок «сначала код, потом анкета» из legacy-файлов и краткой первоначальной MVP-матрицы.
6. Вход по коду и почтовый кабинет также остаются отдельными точками входа; существующий готовый заказ открывается без повторной генерации.
7. Гостевой черновик не является заказом. Требуется определить его безопасное хранение, продолжение после OTP/перезагрузки и передачу в server-side заказ.
8. При неизвестном времени рождения нельзя выдумывать дома и углы; фактические server-status управляют интерфейсом, а не декоративный таймер.
9. На первом проходе в Cursor **только архитектурные документы и план**. Реализация после согласования.

## Решения 11.11.2026 (согласование архитектуры)

## Открытые вопросы
- Выбор астрономической библиотеки/движка в новой Go-реализации требует отдельного сравнения и тестов точности.
