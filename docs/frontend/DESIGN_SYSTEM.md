# Личный космос 2.0 — DESIGN_SYSTEM v1

**Статус:** дизайн-направление утверждено по изображению hero от 11.11.2026; конкретные токены ниже — проектные рабочие значения для визуальной проверки, а не извлечённые оригинальные CSS-значения.

## 1. Source of truth
- `docs/frontend/references/hero-approved.png` — **утверждённый визуальный эталон**; проверяйте композицию, атмосферу и иерархию именно по этому изображению.
- `SCREEN_SPEC_MVP_v2.md` — продуктовый путь A, экраны, действия.
- `MOTION_SPEC.md` — переходы и состояния анимации.
- Если токен конфликтует с визуальным эталоном, сначала проверяем на работающем экране и согласуем поправку; агент не редизайнит исходный hero самостоятельно.
- Исходный скриншот содержит нижнюю интерфейсную панель предпросмотра: она **не является элементом сайта**, не воспроизводить её.

## 2. Визуальный язык
Премиальная кинематографичная editorial эстетика, **не** sci-fi dashboard и **не** астрологические клише (яркий фиолетовый, неон, стеклянные карточки на каждом шаге). Основа: темно-синее ночное пространство, крупная реалистичная планета справа, теплая контровая подсветка, тонкие линии орбит, мелкие звезды, горный горизонт, легкая атмосферная дымка. Контент лаконичный, воздуха много. Космическая сцена — фон, не препятствие чтению.

## 3. Композиция утверждённого первого экрана
- Desktop: полноэкранный / почти полноэкранный hero; основная типографика слева, планета доминирует справа, линия горизонта и нижний editorial-блок у нижней части кадра.
- Текст первого экрана: надзаголовок «ИСКУССТВО УЗНАВАТЬ СЕБЯ», заголовок «У каждого —» / «свой космос.», описание, CTA «Построить мою карту», вторичный «Смотреть пример».
- Разделить заголовок на крупную **светлую sans** строку и **золотистую italic serif** строку. Контраст размеров и шрифт — часть айдентики.
- Микроэлементы: очень тонкие орбиты, небольшие подписи, золотистые астрономические символы, минимальные разделители. Не превращать подписи в функциональные кнопки без UX-основания.
- На ширине 1440+: герой избегает обрезания ключевого заголовка и CTA. Планета может частично выходить за правый край. На mobile планета уходит в верхнюю/фоновую часть, текст и CTA остаются читаемыми. Никакого горизонтального скролла.
- Изображение считается референсом внешнего вида, **не** доказательством наличия исходной 3D-модели или конкретных шрифтов. Для реализации нужны легально используемые ассеты и отдельная проверка их лицензий.

## 5. Типографика
- Заголовок: тонкая геометричная sans (например, Manrope / близкая по рисунку), начертание light, свободная ширина букв.
- Выделенная строка: элегантная наклонная serif display (подбирать по сходству с эталоном; например, Cormorant Garamond Italic лишь стартовая гипотеза).
- Основной текст: нейтральная хорошо читаемая sans, 16–18px на desktop, не менее 16px в полях на mobile.
- Микроподписи: uppercase с увеличенным tracking, только там, где они читаемы; не уменьшать текст ради пиксельного сходства.
- Заголовок hero desktop: приблизительно clamp(60px, 6.4vw, 112px); mobile: clamp(42px, 11vw, 72px), проверить переносы русского текста.
- Следить за доступностью: достаточный контраст, 200% zoom, screen reader labels.

## 6. Компоненты
- `PrimaryCTA`: светлая теплая прямоугольная кнопка, темный текст, тонкая стрелка вправо; hover — легкое смещение стрелки/подсветка, без резкого масштабирования.
- `SecondaryCTA`: прозрачная кнопка-ссылка с кольцевым знаком play/arrow, не маскировать под главный CTA.
- `Field`: темная сдержанная подложка или подчеркивание, светлый текст, понятный label, outline focus, ошибки под полем (не только цвет).
- `ProgressStep`: тонкая линия/номер `01 / 04` и текстовый статус для ассистивных технологий.
- `CelestialBackdrop`: общий слой сцены, который продолжается между этапами без скачков.
- `EditorialSection`, `ChartView`, `ReadingSection`, `ResultDownload`, `AccessCodeInput`, `OTPInput`.
- Модальные окна только для локальных решений. Основные продуктовые шаги должны иметь адресуемые маршруты.

## 8. Поведение, адаптивность, доступность
- Контрольные viewport: 390×844, 768×1024, 1440×900, 1920×1080; отдельно проверить 320px и увеличение 200%.
- Без горизонтальной прокрутки. Интерактивные цели ориентировочно не менее 44×44 CSS px.
- Все анимации должны уважать `prefers-reduced-motion`, клавиатурную навигацию и focus management при смене маршрутов.
- При отключенном WebGL/низкой производительности показывать полноценный визуальный fallback без блокировки формы и результата.
- Не брать браузерный рендер камеры или картинки за подтверждение астрономической точности: координаты поступают от сервера.
- Не применять эффекты на текстовых разделах ценой ухудшения читабельности.

## 9. Проверка визуальной точности
1. Скриншот hero на 1440×900 и на mobile, сравнение с утверждённой композицией; различия описывать явно.
2. Проверка гарнитур/переносов русского текста, контраста, CTA, обрезки планеты.
3. Проход всех экранов: один визуальный язык; отсутствие случайных шаблонных компонентов.
4. Отдельное утверждение кадров начала/середины/конца главной анимации.

## 10. Что пока НЕ утверждено
- Точные CSS-значения и лицензированные семейства шрифтов.
- Исходный 3D/видео-ассет планеты, точная реализация ее изображения.
- Иллюстративное оформление всех внутренних экранов.
- Длительности и easing: задаются как предлагаемая спецификация в `MOTION_SPEC.md`, требуют проверки на живом frontend.
