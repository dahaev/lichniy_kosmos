- Скриншоты 1440×900 и 390×844 в согласованных состояниях, сравнение с `references/hero-approved-source.png` на уровне визуального языка.

## Сквозной путь
1. CTA на hero открывает `/create` без кода.
2. Четыре шага анкеты, серверный справочник города, unknown time и точность времени.
3. Review и возврат к любому шагу без потери draft.
4. Доступ: код / email; неверный или использованный код не расходуется повторно.
5. Consent и финальный POST с идемпотентностью.
6. Реальная сцена создания и реальные server stages, восстановление после refresh.
7. Результат: карта, текст, иллюстрация, PDF/TXT/PNG; повторное открытие без новой генерации.

## Референсные контрольные точки визуализации
- Hero desktop соответствует утвержденной композиции (планета справа, заголовок слева, теплые акценты и нижний горизонт), но нижний overlay скриншота не копируется.
- Анкета имеет editorial-типографику и общую кинематографичную сцену, не шаблонную SaaS-карточку.
- Scene creation: утвердить три кадра — появление планет, выстраивание, раскрытие карты.
- Result: утвердить заголовок + натальную схему + первый экран текста до массового копирования компонент.
