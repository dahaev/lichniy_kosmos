# Эксплуатация

Runbook'и бэкапа, восстановления и деплоя появляются в срезе 12 (ARCHITECTURE_MVP_v2 §20, §23).

Правила, действующие уже сейчас:
- старый production и его БД не трогаем; legacy-сайт, его DNS и обслуживание не меняются (§26);
- секреты хранятся только в env-файлах на сервере (права 600) и никогда не попадают в Git;
- миграции запускаются отдельным шагом: `docker compose -f deploy/compose.yaml --profile ops run --rm migrate`.
