# Личный космос 2.0 — спецификации для нового проекта

В этом стартовом пакете **нет исходного кода приложения**. Он нужен для первого этапа проектирования в Cursor.

- `docs/PROJECT_DECISIONS.md`: согласованные решения, в частности новый порядок «анкета до активации».
- `docs/product/PRODUCT_MVP_SCOPE_v1.md`: функциональный состав MVP.
- `docs/frontend/`: экраны, дизайн, анимации, критерии UI, утверждённый скриншот.
- `docs/legacy/`: снимок требований старого веб-сервиса 0.13.4, не архитектурное задание.
- `AGENTS.md`: правила агента.

Следующий этап: попросить Cursor провести **проектирование архитектуры без кода**, согласовать результат, затем создавать backend/frontend.
