# assets-src — мастер-файлы сцены

Исходники слоёв сцены: планета, горизонт, дымка, звёздные поля, текстуры. Правила — ARCHITECTURE_MVP_v2 §17.2c.

## Правила
- Файлы хранятся в Git LFS (`.gitattributes`). Перед первым коммитом сюда выполните `git lfs install`.
- Рядом с каждым мастер-файлом лежит `<имя>.LICENSE.md` с происхождением: автор или инструмент, дата, лицензия, ссылка или промпт, ограничения на использование.
- Без файла лицензии ассет в сборку не попадает.
- В мастер-файлах нет текста и элементов интерфейса: текст — только DOM.
- Пластина планеты — не меньше 4096 px по диаметру.
- Временные ИИ-пластины V1 (решение Q16) помечаются в имени и лицензии как `temp-not-for-production`.
- `docs/frontend/references/hero-approved.png` — эталон, а не ассет. Сюда его не копировать.

## Структура (появится в V1)
```
assets-src/
  planet/      planet-master.png + planet-master.LICENSE.md
  horizon/
  haze/
  stars/
```

Экспорт в AVIF/WebP (≈1280 / 1920 / 2880) и KTX2 делает сборочный скрипт V1. В S0 он отсутствует.
